Privacy Policy

gmail-mcp · Last updated: 20 November 2026

gmail-mcp is a personal tool built and used only by its owner, Bo Zheng. It is not offered to the public, and no other users can sign in to it.

What data it accesses

With the owner's authorisation through Google OAuth, the tool reads messages in the owner's own Gmail accounts so it can produce daily summaries and statistics for the owner.

How data is used and stored

Email data is processed on the owner's own computer only to generate those summaries. OAuth tokens are stored locally on that computer. No email content is kept on any server run by this tool.

Sharing

No data is sold, shared with, or transferred to any third party. Google user data is not used for advertising.

Google API Services User Data Policy

This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections.
